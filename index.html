STUDYMATS UPDATES

What's changed

A running summary of improvements to the study dashboard, quiz, and question-bank tools.

OCT 2026 · STUDY EXPERIENCE

Cleaner dashboard and quiz

  • Daily Study Rhythm spacing simplified by removing the extra momentum label.
  • Quiz opens in dark mode by default, with a true-black surface and cleaner, compact question metadata.
  • Quiz timer supports custom duration, quick-add time, and a clear time-up state.
OCT 2026 · STUDY TOOLS

Build and manage question banks

  • Test Bank Builder supports drafting, editing, reusing questions, validating, importing JSON, and exporting a bank without overwriting originals.
  • Dashboard progress includes subject-level glance views and saved activity.
OCT 2026 · APP ACCESS

Install StudyMats

  • Added installable PWA support and a basic offline app shell for supported browsers.

Offline access is limited; question data may still need an internet connection.
