Import a practice exam

Have a practice exam in PDF, Word, or text? Use the short guide below to convert it with an AI assistant, then upload the JSON file here. Your existing question banks will not be changed.

Quick tutorial
  1. Open the Make an AI prompt tab and copy the conversion prompt below.
  2. In your AI chat, attach your practice exam file and paste the prompt.
  3. Ask the AI to return a downloadable .json file, or copy its JSON output into a text file named practice-exam.json.
  4. Upload the JSON file here, then click Validate and import JSON.

Check the answer key and rationales against your source before using imported questions.

Accepted format: a JSON array of question objects. This imports into your current draft only; it does not publish to or overwrite a subject bank.
